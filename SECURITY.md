# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting:
**Security** tab -> **Report a vulnerability**
(https://github.com/createcentury/cholqr/security/advisories/new).

I aim to reply within 7 days.

A numerical result that is less accurate than documented (for example, orthogonality worse than a stated bound) is a
bug, not a vulnerability: please report it as a normal issue, ideally with the input and device.
