# Pre-registration: lambda_2 = sigma_min^2 / (sigma_min^2 + s) as the gate of an FP32 scqr3 breakdown (2026-11-14)

Written and committed before any run of `benchmarks/lam2_check.py` (code, predictions and judge `benchmarks/lam2_judge.py` are
committed together). `--smoke` prints timings only and writes nothing. CPU only (Apple M4), torch 2.15.0, precision "highest",
FP32, instrumented mirror of cholqr 0.5.1's scqr3 passes (`device_sweep.mirror`).

## Question

By T0 (note Sec. 2), after the shifted first pass the smallest eigenvalue of the pass-2 Gram matrix is, in exact arithmetic,
$\lambda_2 = \sigma_{\min}^2/(\sigma_{\min}^2 + s)$, with $\sigma_{\min}$ the smallest singular value of the column-normalised input and $s = 10^{-6} l$.
Does a breakdown (any pass with `info > 0` or a non-finite factor) only occur when $\lambda_2$ is of the order of a few unit roundoffs
$u = 2^{-24}$, at sizes not used to find the pattern?

## What is already known (seen; post hoc)

In the existing device-sweep records (12 sweeps, 8785 FP32 scqr3 runs, $m \in \{1024, 4096\}$, $l \in \{64, 276\}$, six spectra, precision "highest")
no run failed with $\lambda_2 \ge 2.2u$ (largest $\lambda_2/u$ among failed runs: 0.83 at $l = 64$, 2.13 at $l = 276$, both Apple M4 CPU; at most 1.1 on other devices).
Failure fraction against $\lambda_2/u$ in the M4 CPU sweep: 56-100% below 0.1, 31% in [0.1, 1), 11% in [1, 10), 0% above 10. The threshold
appears to grow with $l$ (two points only). This pattern was found after the data were seen: this registration is its test.

## Design

$(m, l) \in \{(1680, 210), (3072, 210), (4096, 512)\}$; six spectra (construction of `device_sweep.py`); nominal cond $10^{3}, 10^{3.5}, \dots, 10^{10}$ (15 values);
draws 1-3 (seed prefix `L2-`, new draws); method scqr3 only. 810 inputs. Failed run: any pass with `info > 0` or non-finite Cholesky factor.
$\lambda_2$ from the FP64 SVD of the first-pass input after column normalisation, with the first-pass shift $s = 10^{-6} l$.

## Predictions

- **H1** $l = 210$ (both $m$): no failed run among runs with $\lambda_2 \ge 10u$ (and at least 20 such runs exist).
- **H2** $l = 512$: no failed run among runs with $\lambda_2 \ge 10u$ (at least 20 such runs). (Lower confidence: the threshold grows with $l$; the extrapolation from the two known sizes is about 3u.)
- **H3** In each $l$, at least 50% of runs with $\lambda_2 < 0.1u$ failed (at least 20 such runs).
- **H4** The largest $\lambda_2/u$ among failed runs is larger at $l = 512$ than at $l = 210$.
- **H5** Every failed run fails first in pass 2.

Consequence: if H1 and H2 hold, the note may state "a breakdown needs $\lambda_2 \lesssim 10u$ (observed up to $l = 512$)" as an empirical rule with its
registration; if H2 fails, the threshold grows faster than $10u$ at $l = 512$ and the rule is stated for $l \le 276$ with the new data reported. H3/H4 failing
only weakens the description of the gray zone. Nothing in cholqr changes on the basis of this run alone.
